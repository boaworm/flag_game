# Asset and data attribution

## Flags — `assets/flags/`

SVG flags in 4:3 aspect ratio, one per country, named by lowercase ISO 3166-1
alpha-2 code.

- **Source:** [flag-icons](https://github.com/lipis/flag-icons) by Panayiotis
  Lipiridis
- **License:** MIT
- **Retrieved:** 2026-09-28

Copied from the project's `flags/4x3/` directory. Only the 193 flags matching the
countries in `data/countries.json` are vendored here.

## Country data — `data/countries.json`

Generated by `tools/build-countries.mjs`, not edited by hand.

- **Source:** [mledoze/countries](https://github.com/mledoze/countries)
- **License:** ODbL 1.0 (Open Database License) for the data
- **Retrieved:** 2026-09-28

Filtered to the 193 UN member states. One correction is applied in the generator:
the source marks the Holy See as a UN member, but it is a permanent observer state.

## Map — `assets/map/`

Not yet added. The intended source is [Natural Earth](https://www.naturalearthdata.com/)
(public domain), simplified and projected at build time.
